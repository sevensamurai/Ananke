## What's new

Initial release of Ananke — vendor-agnostic workflow orchestration framework for .NET.

### Packages

| Package | Description |
|---|---|
| `Ananke` | Meta-package |
| `Ananke.Abstractions` | Shared interfaces and contracts |
| `Ananke.StateMachine` | Distributed FSM engine with middleware pipeline |
| `Ananke.Orchestration` | Workflow builder, runner, agents, checkpointing, knowledge pipeline |
| `Ananke.Orchestration.OpenAI` | OpenAI provider |
| `Ananke.Orchestration.Anthropic` | Anthropic / Claude provider |
| `Ananke.Orchestration.Google` | Google Gemini provider |
| `Ananke.MCP` | MCP server integration |
| `Ananke.A2A` | A2A (Agent-to-Agent) protocol integration |
| `Ananke.Documents` | PDF + Markdown extraction for knowledge ingestion |
| `Ananke.Qdrant` | Qdrant vector database provider |
| `Ananke.Redis` | Distributed lock and key-value store via Redis |
| `Ananke.MQTT` | Pub/sub channels via MQTTnet |
| `Ananke.OpenTelemetry` | OTLP tracing export |
| `Ananke.Design` | YAML manifest import and Mermaid diagram export |

## Breaking changes

None — initial release.
