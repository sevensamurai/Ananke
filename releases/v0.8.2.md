# Ananke v0.8.2

**Theme: `nnke` scaffold reliability — generated projects compile and run out of the box.**

No library or API changes. This patch is a comprehensive fix pass on the `nnke` developer tool:
all ten supported workflow patterns now produce projects that restore, compile, and run without
any manual edits after scaffolding.

## What's new

- **`nnke new workflow` — all patterns compile** — end-to-end smoke tests pass for `etl`,
  `sequential`, `fan-out`, `human-in-the-loop`, `sub-workflow`, `review-critique`,
  `iterative-refinement`, `router`, `handoff`, `streaming-chat`, and `organic-host`.
- **`streaming-chat` and `organic-host` patterns added** — previously rejected by the CLI;
  both are now first-class scaffold targets with dedicated `Program.cs` and `.csproj` templates.
- **Template resource loading fixed** — `.cs.template` embedded resources were silently dropped
  at runtime because MSBuild treated the `.cs` segment as a satellite-assembly culture code.
  The `nnke.csproj` now embeds them with `WithCulture="false"` so they load from the main assembly.
- **Template encoding cleaned** — all template files are plain ASCII / BOM-less UTF-8; no more
  mojibake characters (e.g. `ΓÇö`) appearing in generated source comments.
- **Template filename convention unified** — all scaffold resources use the `.{ext}.template`
  naming scheme; the previous mixed `-.template` / `.template` inconsistency is gone.
- **Streaming event shape corrected** — `program-streaming-chat.cs.template` now uses
  `WorkflowCompleted<ChatState>` and accesses `completed.Result.FinalState.LastResponse`
  (previously used a non-existent `WorkflowEvent<T>.Completed` shape).
- **Missing `Workflows` namespace imports added** — several `Program.cs` templates were missing
  `using Ananke.Orchestration.Workflows;`, causing `Workflow<T>` and `Workflow.End` compile errors.
- **`AddEnvironmentVariables()` removed from generated code** — the extension method requires
  `Microsoft.Extensions.Configuration.EnvironmentVariables`, which is not referenced by the
  scaffolded projects; the call has been removed so the generated code compiles without adding
  an extra package dependency.
- **Default scaffold simplified** — `nnke new workflow <name>` (no `--pattern`) now generates
  a minimal runnable quickstart-style workflow instead of a manifest-heavy scaffold that required
  additional runtime setup.

## `nnke` documentation

- `README.md` updated to match all real command names and signatures:
  - Added `nnke run` and `nnke serve` to the command table (both were wired but undocumented).
  - Fixed `nnke mesh trace` and `nnke mesh inspect` examples — previous docs showed non-existent
	`nnke mesh cell trace` and `nnke mesh memory inspect` subcommand paths.
  - Added a full **Patterns table** listing all ten `--pattern` values with style and description.
  - Added a **Providers table** documenting `openai`, `anthropic`, and `google` scaffold targets.
  - Added `streaming-chat` to usage examples.
