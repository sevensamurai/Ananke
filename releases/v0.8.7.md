# Ananke v0.8.7

**Theme: composition-boundary fixes, a model lifecycle system, and zero-warning hardening**

An independent implementation review of v0.8.6 covering the surfaces downstream consumers
(Zenzique, PoC-interview, PoC-agency) build against. No new features — this release is bug fixes,
ergonomics, and API cleanup on the path to 1.0, per the roadmap.

---

## What's new

### Model catalog unification + lifecycle system

- `Models` moved from `Ananke.Design` to `Ananke.Abstractions.Agents` (see Breaking changes) and
  all three providers' registrations caught up to their current lineups (Claude, OpenAI's GPT-5
  family, Gemini 3.x).
- Added OpenAI's newly-released **GPT-5.6** family (`Gpt56Sol`/`Gpt56Terra`/`Gpt56Luna`) as the
  new Current tier, superseding GPT-5.4/GPT-5.5 (now Legacy) and GPT-5.2 (now Deprecated) —
  see `docs/reference/model-deprecations.md` for the full replacement table.
- New `ModelStatus` lifecycle (`Current`/`Legacy`/`Deprecated`/`Retired`) on both `ModelCatalog`
  implementations, with `ReplacedBy` pointers and a one-time deprecation-warning log from
  `CapabilityModelRouter`.
- Compile-time deprecation (`[Obsolete]`/`ANNKE001`) plus a new Roslyn analyzer catching deprecated
  or retired model id string literals (`ANNKE002`/`ANNKE003`), both enforced as build errors.
- Six model identifiers confirmed retired by their providers were removed outright rather than
  left flagged (see Breaking changes); provider defaults (`AnthropicAgentModel`, the `nnke` CLI
  scaffold) no longer hardcode a model string.

### Composition-boundary fixes

- `CachingAgentModel` cache keys now include model identity — two models sharing one cache adapter
  no longer serve each other's responses.
- `MiddlewareAgentModel` gains a `Buffered` streaming mode so guardrails can block a response
  before any chunk reaches the consumer (previously PII/deny rules only fired after the full
  stream had already been shown).
- `TextAgentJob`/`AgentJob` retry now uses a `shouldRetry` predicate — permanent failures (auth
  errors, `GuardrailException`) are no longer retried and burned against the retry budget.
- Malformed tool-call JSON from a model is fed back as a correctable `ToolResult.Error` instead of
  crashing the job.
- `InterviewBuilder` no longer requires a welcome/icebreaker opener; `Interview<TState>` transcript
  writes moved to an explicit, idempotent `CommitTurnAsync` (see Breaking changes).

### Reliability & tooling

- `TimeProvider` sweep across empirical memory, `CachingAgentModel`, and checkpoint stores (decay
  and expiry math no longer reads the ambient clock); a new analyzer (`ANANKE_TIME_001`) bans
  `DateTime(Offset).Now/UtcNow` in production code going forward.
- Encoding/lint repair: one canonical UTF-8-without-BOM/LF policy across `.editorconfig` and
  `.gitattributes`, `scripts/fix-encoding.ps1` (CI-checkable), and several pre-existing mojibake
  fixes that had been silently masked by BOM presence. `dotnet format --verify-no-changes` works
  again.
- Fixed a flaky Organics test (`ResumeAsync_CellContinues`) and a Redis checkpoint bug that
  persisted already-expired checkpoints with no TTL.

### Deferred

A non-blocking CI job building the sibling Zenzique/PoC-interview/PoC-agency repos against this
branch is **out of scope for this release** — it needs repo access this branch doesn't have.
Tracked internally for a future release.

## Breaking changes

### `Models` moved from `Ananke.Design` to `Ananke.Abstractions.Agents`

**Who is affected:** any code with `using Ananke.Design;` referencing `Models.OpenAI.*` /
`Models.Anthropic.*` / `Models.Google.*` directly.

**Migration:** add `using Ananke.Abstractions.Agents;`. If the same file also uses `Ananke.Design`
types (`ModelDefinition`, `ModelCatalog`, etc.), keep both usings.

### Six model identifiers removed (provider-confirmed retired)

| Removed | Replacement |
|---|---|
| `Models.Anthropic.Opus4` (`claude-opus-4`) | `Models.Anthropic.Fable5` |
| `Models.Anthropic.Sonnet4` (`claude-sonnet-4`) | `Models.Anthropic.Sonnet5` |
| `Models.Anthropic.Sonnet35` (`claude-3-5-sonnet`) | `Models.Anthropic.Sonnet5` |
| `Models.Anthropic.Haiku35` (`claude-3-5-haiku`) | `Models.Anthropic.Haiku45` |
| `Models.Google.Gemini20Flash` (`gemini-2.0-flash`) | `Models.Google.Gemini35Flash` |
| `Models.Google.Gemini20FlashLite` (`gemini-2.0-flash-lite`) | `Models.Google.Gemini31FlashLite` |

**Migration:** switch to the replacement constant. See `docs/reference/model-deprecations.md` for
sourcing and the full lifecycle table.

### `Interview<TState>` no longer writes conversation memory as a side effect

**Who is affected:** any host using `AgenticPattern.Interview` with `WithMemory(...)` configured.

**Migration:** `GetQuestion`/`FoldAnswer` are now pure — call the new
`Interview<TState>.CommitTurnAsync(state, question, answer, ct)` once after `ResumeAsync` succeeds
to persist the turn. The call is idempotent (a repeated identical question/answer pair is a no-op),
but it must be called explicitly; nothing writes the transcript automatically anymore.
