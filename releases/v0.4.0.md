# Ananke v0.4.0

**Theme: skills that travel and agents that think independently.**

Three capability pillars land in this release:

- **`Ananke.Learning`** — a dedicated package for empirical memory, episodes, reinforcement strategies, and portable skill packaging. Previously scattered across `Ananke.Orchestration.Memory`; now a first-class library with its own vertical slices.
- **`Ananke.Skills`** — a brand-new package for discovering and resolving external community skills (OpenClaw/ClawHub) into `ToolDefinition` entries with zero protocol overhead.
- **Orchestration additions** — fluent multi-parameter tool authoring (`ToolBuilder` / `ToolArgs`), two agentic design patterns (Iterative Refinement, Review and Critique), and cross-document knowledge linking.

---

## What's new

### `Ananke.Learning` — dedicated learning package (new)

All empirical memory and learning types previously in `Ananke.Orchestration.Memory` have been
extracted into a focused standalone package organized by vertical slice.

**`IEmpiricalMemory`** and its in-process implementation `InMemoryEmpiricalMemory` are the
unchanged core. See the v0.3.0 notes for the full affective-signal model. The package extends
them with:

---

#### Episodes — `Ananke.Learning.Episodes`

Trajectory storage for temporal credit assignment. An `Episode` is an ordered sequence of
`EpisodeStep` entries (each linking to an `EmpiricalEntry`) ending in a terminal reward.

| Type | Description |
|---|---|
| `IEpisodeStore` | Read/write store for completed episodes |
| `InMemoryEpisodeStore` | Default in-process implementation |
| `Episode` / `EpisodeStep` | Immutable trajectory records |
| `IRewardPropagator` | Contract for distributing terminal reward back through steps |
| `MonteCarloRewardPropagator` | Built-in Monte Carlo return: `r × γᵏ` per step |

```csharp
var episode = new Episode
{
    Id = Guid.NewGuid().ToString("N"),
    Steps = steps,
    TerminalReward = 1.0f,
    StartedAt = start,
    CompletedAt = DateTimeOffset.UtcNow
};

await episodeStore.SaveAsync(episode);

// Propagate reward back through the trajectory and reinforce each entry:
await propagator.PropagateAsync(episode, memory);
```

---

#### Exploration strategies — `Ananke.Learning.Exploration`

Domain-agnostic action selection balancing exploitation and exploration.

| Type | Description |
|---|---|
| `IExplorationStrategy` | Selects an action index from scored `ActionCandidate` entries |
| `UcbExplorationStrategy` | Upper Confidence Bound with optional variance bonus |
| `EpsilonGreedyExplorationStrategy` | ε-greedy with annealed decay |
| `ExplorationOptions` | Shared tuning knobs (UCB coefficient, ε-initial, ε-min, decay) |

```csharp
var strategy = new UcbExplorationStrategy(new ExplorationOptions
{
    ExplorationCoefficient = 1.414f,
    UseVarianceBonus = true
});

int chosen = strategy.SelectAction(candidates, totalSelections: 42);
```

---

#### Tag importance — `Ananke.Learning.Features`

Learns which semantic tags correlate with good or bad outcomes by analyzing entries with
non-zero `Valence`.

| Type | Description |
|---|---|
| `ITagImportanceTracker` | Computes a `TagImportanceMap` from an `IEmpiricalMemory` |
| `TagImportanceTracker` | Default mean-valence implementation |
| `TagImportanceMap` | Read-only tag → importance weight dictionary |
| `TagImportanceOptions` | `MinSampleSize` gate (default: 10 entries) |

The map is consumed by `SkillPackager` during export to weight entries by feature relevance.

#### Offline learning — `Ananke.Learning.Offline`

`IOfflineLearner` and `OfflineLearner` are unchanged in contract (see v0.3.0 notes) and are

> **Migration:** replace `using Ananke.Orchestration.Memory;` with `using Ananke.Learning.Offline;`

#### Portable skill packages — `Ananke.Learning.Skills`

Export high-confidence empirical entries as portable packages that other agents or teams can
import. Quality gates on export; trust scaling on import.

| Type | Description |
|---|---|
| `ISkillPackager` | Export and import contract |
| `SkillPackager` | Default streaming implementation (pages through `BrowseAsync`) |
| `ISkillPackageFormat` | Reader/writer abstraction |
| `JsonSkillPackageFormat` | Built-in JSON line-delimited format |
| `SkillExportOptions` | Quality gates: `MinConfidence`, `MinObservations`, `MinStrength`, `MaxVariance`, `IncludeEpisodes` |
| `SkillImportOptions` | Trust scaling: `TrustScale`, `MergeMode` |
| `SkillExportResult` / `SkillImportResult` | Summary of what was exported / imported |

```csharp
// Export
var packager = new SkillPackager();
var format   = new JsonSkillPackageFormat();

using var stream = File.OpenWrite("investigation-skills.json");
await using var writer = format.CreateWriter(stream);

var result = await packager.ExportAsync(
    new SkillExportOptions
    {
        Name        = "incident-investigation",
        Domain      = "sre",
        Version     = "1.0.0",
        MinConfidence    = 0.7f,
        MinObservations  = 3,
        IncludeEpisodes  = true
    },
    memory, writer, episodeStore, tagMap);

// Import on another agent
using var src = File.OpenRead("investigation-skills.json");
await using var reader = format.CreateReader(src);

await packager.ImportAsync(reader, memory, episodeStore,
    new SkillImportOptions { TrustScale = 0.8f });
```

### `Ananke.Skills` — external skill catalog (new)

Discover, score, and resolve community-contributed CLI tools into `ToolDefinition` entries
without MCP or any external protocol. Ships the OpenClaw/ClawHub catalog as the first
built-in implementation.

#### `ISkillCatalog` — protocol-agnostic discovery

```csharp
// Search offline cache
IReadOnlyList<SkillDescriptor> results = await catalog.SearchAsync(
    "find available airbnb listings", tags: ["travel"], limit: 5);

// Resolve into a runnable ToolDefinition
ToolDefinition tool = await catalog.ResolveAsync(results[0]);

// Sync the remote registry into the local cache
await catalog.SyncAsync();
```

#### `OpenClawCatalog` — OpenClaw/ClawHub

Caches catalog JSON locally and bridges each skill via `CliProcessRunner` (direct `uvx` /
`npx` / `pipx` invocation — no in-process MCP server). Optional vote-based reliability
scoring is persisted by `JsonFileScoreStore`.

```csharp
var catalog = new OpenClawCatalog(
    cacheDir: "~/.ananke/skills",
    scoreStore: new JsonFileScoreStore("~/.ananke/scores.json"),
    enableVoting: true);          // up/down vote on every tool execution

await catalog.SyncAsync();        // populate the local cache on startup
```

#### `ToolKitSkillExtensions.AddFromCatalogAsync` — fluent toolkit population

```csharp
var kit = await new ToolKit("research")
    .AddFromCatalogAsync(catalog, "search for academic papers", limit: 3);
```

#### `SkillDescriptor` — lightweight metadata

| Property | Description |
|---|---|
| `Id` | Unique catalog identifier (e.g. `"stveenli/airbnb"`) |
| `Name` | CLI package name |
| `Tags` | Keywords for search ranking |
| `Install` | Runner (`Uvx`, `Npx`, `Pipx`, `Direct`) |
| `Parameters` | Typed CLI parameter list mapped to JSON Schema |
| `ExtraCliArgs` | Fixed CLI flags appended to every invocation (e.g. `"--json"`) |
| `Score` | Local reliability score from `ISkillScoreStore` |

### Fluent tool authoring — `ToolBuilder` and `ToolArgs` (`Ananke.Orchestration`)

`ToolBuilder` replaces manual `ToolDefinition` construction for tools with two or more
parameters. `ToolArgs` provides type-safe access to LLM-supplied arguments, handling
`JsonElement` deserialization transparently.

```csharp
toolkit.AddTool("buy_shares", "Buy shares of a stock", b => b
    .Param("symbol",   "Ticker symbol",      examples: ["AAPL", "MSFT"])
    .Param<int>("quantity", "Shares to buy")
    .Tags("trading", "market")
    .Requires("authenticated", "User must be authenticated")
    .OnExecute(async (args, ct) =>
    {
        var symbol = args.Get("symbol");
        var qty    = args.Get<int>("quantity");
        return ToolResult.Ok($"Bought {qty} × {symbol}");
    }));
```

`ToolArgs.Get<T>()` maps JSON Schema types automatically:

| CLR type | JSON Schema type |
|---|---|
| `int` / `long` | `"integer"` |
| `float` / `double` / `decimal` | `"number"` |
| `bool` | `"boolean"` |
| everything else | `"string"` |

### Agentic design patterns (`Ananke.Orchestration`)

Two common multi-agent topologies are now expressible as one-liner fluent builders via
`AgenticPattern`:

#### Iterative Refinement

A single agent refines its output in a self-loop until a quality predicate is satisfied.

```csharp
var workflow = AgenticPattern.IterativeRefinement<DraftState>("polish")
    .WithAgent("writer", async (state, ct) => await WriteAsync(state, ct))
    .Until(s => s.Score >= 0.9f)
    .MaxIterations(8)
    .OnLoopExit((s, reason) => logger.LogInformation("Stopped: {Reason}", reason))
    .Build();
```

#### Review and Critique

A generator and an independent critic alternate in a feedback loop.

```csharp
var workflow = AgenticPattern.ReviewCritique<ReviewState>("review")
    .WithGenerator("writer",   async (s, ct) => await GenerateAsync(s, ct))
    .WithCritic("critic",      async (s, ct) => await CritiqueAsync(s, ct))
    .Until(s => s.Approved)
    .MaxIterations(5)
    .Build();
```

`LoopExitReason` — `ConditionMet` or `MaxIterationsReached` — is delivered to the
`OnLoopExit` callback.

### Cross-document knowledge linking (`Ananke.Orchestration`)

An opt-in decorator layer adds a link graph on top of `IKnowledgeStore`. When enabled,
search results are expanded through related documents via graph traversal.

```csharp
services.AddSingleton<IKnowledgeStore>(sp =>
    new InMemoryKnowledgeStore(sp.GetRequiredService<IEmbeddingModel>()));

services.AddKnowledgeLinking(options =>
{
    options.AutoLinkOnIngest      = true;
    options.SimilarityThreshold   = 0.75f;
    options.SearchOptions = new LinkedSearchOptions
    {
        ExpansionSeeds    = 5,
        MaxHops           = 2,
        GraphScoreDiscount = 0.7f
    };
});
```

| Type | Description |
|---|---|
| `IDocumentLinkGraph` | Read/write graph of document-to-document links |
| `InMemoryDocumentLinkGraph` | Default in-process implementation |
| `LinkedKnowledgeStore` | Decorator that expands search via graph traversal |
| `DocumentLinkExtractor` | Optional LLM-based post-ingestion link discoverer |
| `KnowledgeLinkingExtensions` | `AddKnowledgeLinking(options)` DI registration |

Composes with `CatalogAwareKnowledgeStore`; decorator order does not matter.

### `RedisCheckpointStore` (`Ananke.Redis`)

Redis-backed `ICheckpointStore` for distributed workflow checkpointing. Each checkpoint is
stored as a JSON string under key `{prefix}:{executionId}`. Native TTL is applied via
Redis `EXPIREAT` when `Checkpoint<TState>.ExpiresAt` is set.

```csharp
var store = new RedisCheckpointStore(redis, prefix: "myapp:checkpoint");
```

### `Ananke.Learning` extraction

All empirical memory and learning types have been moved out of `Ananke.Orchestration` into
the new `Ananke.Learning` package. Add a package reference to `Ananke.Learning` and update
namespace imports:
