# Ananke v0.8.1

**Theme: `nnke` tooling fix — scaffolded projects now restore correctly from NuGet.**

No library or API changes. This patch fixes a bug in `nnke new workflow` (and all other `nnke new` subcommands) where the generated `.csproj` file contained `<PackageReference>` entries without `Version` attributes. Because the scaffolded project lives outside the solution directory it has no access to `Directory.Build.props` or `Directory.Packages.props`, so NuGet restore failed immediately after scaffolding.

Version values are now baked into the `nnke` binary at build time via an MSBuild source-generation target, so the emitted `Version` attributes always match the published package versions with no manual maintenance required.

## Root cause

`TemplateEngine` emitted bare `<PackageReference Include="Ananke.Orchestration" />` tokens. The fix injects `$(VersionPrefix)` and `$(MsExtensionsVersion)` from `Directory.Build.props` into a generated `TemplateEngine.Versions.g.cs` at compile time, and the templates use `{{ananke_version}}` / `{{ms_extensions_version}}` placeholders that resolve at scaffold time.

None.
