# Ananke v0.7.1

**Theme: CI hotfix — `nnke` tool now publishes correctly to NuGet.**

No library or API changes. This patch fixes the v0.7.0 publish pipeline where the `nnke` dotnet tool package was blocked with HTTP 403 because the single NuGet API key was scoped to the `Ananke*` glob and did not cover the `nnke` package ID.

## Breaking changes

None.

| Package | Change |
|---|---|
| All `Ananke.*` | Version bump to 0.7.1 (no functional changes) |
| `nnke` | Version bump to 0.7.1; first successful publish to NuGet |
