# Ananke v0.5.0

**Theme: developer experience, API usability & multi-model intelligence.**

Four capability pillars land in this release:

- **Type-safe workflow graph** — `JobRef` wrappers and `out` overloads shift job-name typos from runtime to compile time. A new Roslyn analyzer (`ANANKE001`) catches remaining string literals at the build step.
- **Simpler agent job entry point** — `TextAgentJob` covers the 80 % case where you want the model's plain-text response without JSON schema enforcement.
- **Unified multi-model cost model** — `ModelCostRates`, `IModelCostResolver`, and `ModelCatalog` give accurate per-call budget tracking in multi-model workflows. 25 well-known model templates across 6 providers are bundled.
- **Per-entity memory** — `IEntityMemory` and `IEntityMemoryProvider` in `Ananke.Learning` provide a unified, scoped memory facade per user / device / customer, composing conversation, empirical, knowledge, and episode stores with zero physical partitioning.

## What's new

### `JobRef` — type-safe workflow connections

`JobRef` is a readonly record struct returned by `.Job()` overloads. Pass it to `.Then()`, `.Chain()`, `.Loop()`, and all other connection methods to catch typos at compile time instead of at `Build()` / run time.

```csharp
var workflow = new Workflow<MyState>("pipeline")
    .Job("research", researchFunc, out var research)
    .Job("draft",    draftFunc,    out var draft)
    .Then(research, draft)
    .Then(draft, Workflow.EndRef);   // type-safe End sentinel
```

All builder methods have `out JobRef` overloads:
`Job`, `SubFlow`, `Then`, `Loop`, `Join`, `Chain`, `OnEnter`, `OnExit`, `Timeout`, `InterruptBefore`, `InterruptAfter`, `Workflow.Fork(params JobRef[])`.

Implicit `JobRef → string` conversion preserves full interop with the string-based API.

### `ANANKE001` — Roslyn analyzer for undefined job names

`Ananke.Analyzers` ships a new `DiagnosticAnalyzer` that warns at **compile time** when a string literal in `Then`, `Loop`, `Chain`, `OnEnter`, `OnExit`, `Timeout`, `InterruptBefore`, or `InterruptAfter` doesn't match any `.Job()` registration in the same fluent chain.

```csharp
new Workflow<MyState>("example")
    .Job("research", ...)
    .Then("reserach", Workflow.End)   // ⚠ ANANKE001 — 'reserach' is not registered
```

The `__end__` sentinel is never flagged. The analyzer walks the complete fluent chain in both directions to collect all registrations.

### `TextAgentJob` — plain-text agent job

A single-type-parameter agent job that returns the model's text response directly — no `TResponse` type, no JSON schema, no deserialization. Created via `AgentJobFactory.Create<TState>(name, model)`.

```csharp
// Before (structured — still available)
var agent = AgentJobFactory.Create<MyState, MyResponse>("name", model)
    .WithPrompt(s => s.Input)
    .MapResult((s, r) => s with { Output = r.Answer })
    .Build();

// After (plain text — new 80 % path)
var agent = AgentJobFactory.Create<MyState>("name", model)
    .WithPrompt(s => s.Input)
    .MapResult((s, text) => s with { Output = text })
    .Build();
```

Supports the same fluent builder API as the structured path: `WithSystemPrompt`, `WithTools`, `WithMemory`, `WithRetry`, `WithContextStrategy`, `WithContextLimit`, `WithMaxToolRounds`, `WithLogger`, `OnResponse`.

### `OnFault` / `OnError` error-handling hooks

Per-job and workflow-level fault handlers are now first-class builder methods:

```csharp
var workflow = new Workflow<MyState>("pipeline")
    .Job("fetch", fetchFunc, out var fetch)
    .Job("process", processFunc, out var process)
    .Then(fetch, process)
    .Then(process, Workflow.EndRef)
    .OnFault(fetch, async (state, ex) =>
    {
        logger.LogError(ex, "Fetch failed");
        await alertService.SendAsync("fetch-failed", ex.Message);
    })
    .OnError(async (state, jobName, ex) =>
    {
        await deadLetterQueue.EnqueueAsync(state, jobName, ex);
    });
```

- **`OnFault(jobName / JobRef, handler)`** — invoked when that specific job throws.
- **`OnError(handler)`** — invoked when *any* job throws; receives state, faulting job name, and exception.
- Per-job handler runs first, then the workflow-level handler. Handler exceptions are logged but do not replace the original fault. Works with both `RunAsync` and `StreamAsync`.

### Unified multi-model cost model

#### `ModelCostRates`

Immutable record holding split input / output rates. Replaces the single blended rate previously used throughout.

```csharp
var rates = new ModelCostRates(
    CostPer1KInputTokens:  0.0004m,   // $0.40 / 1M input tokens
    CostPer1KOutputTokens: 0.0016m);  // $1.60 / 1M output tokens

// Helpers
var local = ModelCostRates.Zero;           // Ollama, llama.cpp, vLLM
var blended = ModelCostRates.Uniform(0.002m);
```

#### `IModelCostResolver`

Optional interface for routers that can resolve per-request cost rates. `CapabilityModelRouter` implements it automatically — no configuration required.

#### `BudgetConfig` — simplified

```csharp
// Model-based costing (rates come from ModelProfile via IModelCostResolver)
workflow.WithBudget(maxCost: 0.50m);

// Flat-rate fallback (backward compatible)
workflow.WithBudget(maxCost: 0.50m,
    costPer1KInputTokens: 0.15m,
    costPer1KOutputTokens: 0.60m);
```

Zero-cost local model calls are tracked (tokens counted) but contribute $0 to budget.

### `ModelCatalog` — well-known model templates

Static registry of 25 model profile templates across 6 providers. Capabilities, context limits, intelligence / speed tiers, and mid-2025 list prices are included. Bind to a live model instance via `ToProfile`:

```csharp
var router = new CapabilityModelRouter(RoutingStrategy.CheapestFit)
    .AddModel(ModelCatalog.OpenAI.Gpt4_1Mini.ToProfile(miniModel))
    .AddModel(ModelCatalog.OpenAI.Gpt4_1.ToProfile(fullModel))
    .AddModel(ModelCatalog.Meta.Llama3_2_3B.ToProfile(ollamaModel));  // zero cost

// Override pricing
var profile = ModelCatalog.Anthropic.Claude35Sonnet
    .ToProfile(myModel, new ModelCostRates(0.003m, 0.015m));

// Name-based lookup
if (ModelCatalog.TryGet("gpt-4.1-mini", out var template)) { ... }
```

Providers: **OpenAI** (GPT-4.1, GPT-4.1 Mini, GPT-4o, o3-mini, o4-mini), **Anthropic** (Claude 3.5 Sonnet/Haiku, Claude 3 Opus), **Google** (Gemini 2.5 Pro/Flash), **Meta** (Llama 3.2 3B/8B), **Mistral** (Nemo), **DeepSeek** (R1).

### Weighted and custom routing strategies

Two new `RoutingStrategy` values on `CapabilityModelRouter`:

```csharp
// Weighted — composite score across cost, speed, intelligence
var router = new CapabilityModelRouter(new RoutingWeights
{
    CostWeight = 0.3m, SpeedWeight = 2.0m, IntelligenceWeight = 1.0m
});

// Custom — arbitrary scoring function
var router = new CapabilityModelRouter(
    p => p.MaxContextTokens / Math.Max(p.CostPer1KTokens, 0.001m));
```

Scoring formula: `−CostPer1KTokens × CostWeight + SpeedTier × SpeedWeight + IntelligenceTier × IntelligenceWeight`. Capability filtering always runs first — only qualifying candidates are scored.

Existing `RoutingStrategy.CheapestFit`, `FastestFit`, `BestFit` are unchanged.

### `WorkflowExecution<TState>` ergonomics

Three new members avoid the double-null-check pattern:

```csharp
var exec = await workflow.RunAsync(state);

if (exec.IsSuccess)  { /* Status == Completed */ }
if (exec.IsFailure)  { /* Faulted | Cancelled | BudgetExceeded */ }

var result = exec.ToResult();  // never null — synthesises from current state if needed
```

`Result` is preserved for backward compatibility.

### `IRouter<TState>` — correct `CancellationToken` default

The default interface method now forwards to the two-parameter overload, so implementations that observe cancellation work correctly out of the box:

```csharp
public interface IRouter<TState>
{
    Task<string> RouteAsync(TState state) => RouteAsync(state, CancellationToken.None);
    Task<string> RouteAsync(TState state, CancellationToken ct);  // implement this
}
```

```csharp
services.AddWorkflowOrchestration(o => o
    .UseCheckpointing()
    .UseMemoryCleanup(TimeSpan.FromMinutes(5))
    .StoreCompletions(false)
    .WithCheckpointTtl(TimeSpan.FromDays(14)));
```

### `UseMemoryCleanup` — TTL-based conversation memory housekeeping

`OrchestrationOptions.UseMemoryCleanup(TimeSpan)` registers `ConversationMemoryCleanupTimer` as a singleton. The timer periodically calls `IConversationMemory.CleanupExpiredAsync` and is disposed by the DI container at shutdown. No `Microsoft.Extensions.Hosting` dependency — uses `System.Threading.Timer`.

### Streaming event helpers

`WorkflowEventExtensions` adds LINQ-style operators for `IAsyncEnumerable<WorkflowEvent<TState>>`:

```csharp
// Filter to a single event type
await foreach (var e in workflow.StreamAsync(state)
    .OfType<MyState, JobCompleted<MyState>>())
{
    Console.WriteLine($"{e.JobName} took {e.Duration}");
}

// Tap — handler fires, all events still flow through
await foreach (var e in workflow.StreamAsync(state)
    .On<MyState, JobStarted<MyState>>(e => Console.WriteLine($"Starting {e.JobName}"))
    .OnAsync<MyState, JobCompleted<MyState>>(async e => await metricsAsync(e)))
{ }
```

| Method | Description |
|---|---|
| `OfType<TState, TEvent>()` | Filters the stream to events of type `TEvent` |
| `On<TState, TEvent>(Action<TEvent>)` | Synchronous tap; all events forwarded |
| `OnAsync<TState, TEvent>(Func<TEvent, Task>)` | Async tap; all events forwarded |

### Per-entity memory — `Ananke.Learning.EntityMemory`

Unified, scoped memory facade per user / customer / device. All stores remain physically shared; isolation is achieved via key prefixing and metadata filtering — no extra collections or tables.

| Type | Description |
|---|---|
| `IEntityMemory` | Facade exposing `Conversations`, `Empirical`, `Knowledge`, `Episodes` scoped to one entity |
| `IEntityMemoryProvider` | Factory with lazy creation and idle eviction (`GetOrCreate` / `EvictAsync`) |
| `EntityMemoryProvider` | Default thread-safe implementation (`ConcurrentDictionary` cache) |
| `EntityScopedConversationMemory` | Prefixes session IDs with entity ID |
| `EntityScopedEmpiricalMemory` | Injects / filters on `EmpiricalEntry.EntityId` |
| `EntityScopedEpisodeStore` | Injects / filters on `Episode.EntityId` |
| `EntityScopedKnowledgeStore` | Injects entity metadata on upsert; filters on search |

```csharp
var provider = new EntityMemoryProvider(conversations, empirical, knowledge, episodes);

// One call — always the same facade instance for the same entity
IEntityMemory memory = provider.GetOrCreate("user-42");

await memory.Conversations.AddAsync("user-42:session-1", message);
await memory.Empirical.CommitAsync(entry);
await memory.Episodes.SaveAsync(episode);

// Release the cached facade (persisted data is NOT deleted)
await provider.EvictAsync("user-42");
```

### `StateMachineChannelWorker` — channel-to-state-machine bridge (`Ananke.StateMachine`)

Connects any `IChannelReader<TContext, TTransition>` directly to an `IActionStateMachine` without hand-written `IBackgroundWorker` implementations.

```csharp
var worker = new StateMachineChannelWorker<Ctx, State, Trans, Notif>(machine)
{
    OnTransition = (ctx, transition, result) =>
        logger.LogInformation("{T} → {S}", transition, result.CurrentState)
};

await reader.ConfigureAsync(config, worker);
```

`TransitionEvent<C, S, T>` — new sealed record carrying context, transition, and `TransitionResult` — is the work item type for optional post-transition background processing.
