## What's new

### Tool metadata — `Tags`, `Examples`, and parameter hints (`Ananke.Orchestration`)

`ToolDefinition` and `ToolParameter` now carry optional metadata that is forwarded to the LLM
in the JSON Schema emitted for each tool call, improving tool-calling accuracy for ambiguous
or format-sensitive parameters.

**`ToolParameter.Examples`** — sample values for a parameter, emitted as the JSON Schema
`examples` annotation:

```csharp
new ToolParameter("date", "ISO-8601 date",
    Examples: ["2025-01-01", "2025-12-31"])
```

**`ToolDefinition.Tags`** — keywords for categorisation, filtering, and discovery.
Also consumed by `AgentCardBuilder` when mapping tools to A2A skills:

```csharp
new ToolDefinition { Name = "search", Tags = ["retrieval", "web"], ... }
```

**`ToolDefinition.Examples`** — sample invocations included in the tool description sent
to the LLM:

```csharp
new ToolDefinition { Name = "search", Examples = ["search for cats", "find AI papers"], ... }
```
